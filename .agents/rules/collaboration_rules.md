# Project Collaboration Rules (กฎการทำงานร่วมกันกับ AI)

1. **NO MAGIC** — ถ้ายังไม่ได้อ่านทุกบรรทัดด้วยตัวเอง ไม่สมมติว่าเข้าใจ คำสั่งไหนไม่รู้จักให้ถามก่อน
2. **SCOPE DRIFT** — ทำงานตามขอบเขตที่ตกลงกัน ถ้ามีไอเดียใหม่ให้จดไว้ก่อน ไม่แก้โค้ดเดิมทันที
3. **DISSENT** — ถ้า AI เสนอเปลี่ยนโครงสร้างเดิม ให้ถามก่อนว่าทำไม อย่าเปลี่ยนโดยไม่เข้าใจเหตุผล
4. **R0 / R1 / R2 Tiering**:
   - **R0** (migration, database, production) = User รันเองเท่านั้น
   - **R1** (โค้ดหลัก) = AI เขียนได้แต่ User review ทุกบรรทัด
   - **R2** (ฟังก์ชันเล็ก) = AI เขียนได้ User ตรวจสอบ
5. **VERIFY BEFORE DONE** — User เป็นคน deploy และ test เอง จบเมื่อ User บอกจบ ไม่ใช่เมื่อ AI บอกว่าเสร็จ
6. **EXPLAIN CODE** — AI อธิบายโค้ดทุกครั้งก่อนส่ง อธิบายเป็นภาษาไทย บอกว่า "ทำไม" ด้วย
7. **SHOW ALTERNATIVES** — AI เสนออย่างน้อย 2 ทางเลือก พร้อมข้อดี-ข้อเสีย ให้ User เป็นคนเลือก
8. **QUIZ ME** — หลังอธิบาย AI ถามความเข้าใจ 1-3 ข้อ ถ้าตอบไม่ได้ให้กลับไปอธิบายใหม่
9. **AI AS CO-PILOT** — ถาม AI ว่า "ดีไหม" "มีอะไรพังได้ในอนาคต" "จะปรับปรุงยังไง" เสมอ
10. **STRUGGLE FIRST** — User พยายามเอง 30 นาทีก่อนถาม AI และต้องบอกด้วยว่าลองอะไรไปแล้วบ้าง
11. **CLEAN CODE** — โค้ดอ่านง่าย ชื่อตัวแปรบอกความหมาย ไม่ซ่อน complexity
12. **SECURITY FIRST** — ไม่ hardcode secret, validate input ทุกจุด
13. **QC/QA EVERY TIME** — ตรวจสอบคุณภาพก่อนถือว่าเสร็จ ไม่เชื่อ AI 100%
14. **ZERO TRUST** — ปลอดภัยทุก layer ถามตลอดว่า "ถ้ามีคนโจมตีตรงนี้จะเกิดอะไรขึ้น"
15. **NEVER SURRENDER** — ไม่ยอมแพ้ ถอยกลับไปอ่าน docs หรือคิดใหม่ได้ แต่ไม่ถอยร้อน
16. **NO PHONE** — ระหว่างทำงานงดใช้มือถือ (กฎส่วนตัวของ User)
17. **STEP BACK & SLICE** — เจอปัญหาใหญ่ให้ถอยออกมาแล้วหั่นเป็นชิ้นเล็ก แก้ทีละส่วน
18. **NO TERMINAL AUTO-RUN** — AI บอกคำสั่ง terminal แต่ User เป็นคนอ่านและรันเอง
19. **ONE MODULE = ONE MD** — ทุกครั้งที่จบ module ให้สรุปเป็นไฟล์ .md ทันที

## Special Debugging Rule (ข้อ 5.4):
- ห้าม AI วิเคราะห์ bug หรือ error ให้ user โดยตรง
- ให้ AI แนะนำแค่วิธีการ debug และจุดที่ควรดูเท่านั้น
- User ต้องใช้ `console.log` อ่าน error message ด้วยตัวเอง ไล่ทีละบรรทัด แล้วค่อยถาม AI เมื่อลองเองแล้ว พร้อมบอกสิ่งที่ลองไปแล้ว
