## 1. ทำอะไรไปแล้ว

### ร้านและเมนู (`apps/catalog`)
| ส่วน | ทำไม |
|---|---|
| `Branch` ชื่อ เบอร์ ที่อยู่ **พิกัด (PostGIS)** เวลาเปิด-ปิด สวิตช์เปิดรับออเดอร์ | ร้านเดียวตอนนี้ แต่เมนูผูกกับสาขา เพิ่มสาขาได้ไม่ต้องแก้โครงสร้าง |
| `Category` / `MenuItem` (รูป, มีขาย/หมด, ลำดับ) / `MenuOption` (ตัวเลือกเสริม +ราคา เลือกได้หลายอย่าง) | |
| `shop_status()` | รับออเดอร์ได้เมื่อ: มีร้าน + **มีพิกัด** + เปิดสวิตช์ + อยู่ในเวลาเปิด (รองรับเปิดข้ามเที่ยงคืน) — ไม่มีพิกัดสำรอง |
| `storefront_menu()` | ดึงเมนูทั้งหน้า **query คงที่** ไม่ว่ามีกี่เมนู (มี test) |

### ตะกร้า / สั่ง / สถานะ (`apps/orders`)
| ส่วน | ทำไม |
|---|---|
| ตะกร้าใน session (`cart_service`) | ยังไม่ล็อกอินก็ใส่ได้ · เก็บแค่ id/จำนวน/ตัวเลือก · **ราคาคิดใหม่จากฐานข้อมูลทุกครั้ง** ส่งราคาปลอมมาก็ไม่มีผล · เมนูถูกลบ/หมด จะถูกตัดหรือเตือน |
| ค่าส่ง (`pricing_service`) | ระยะเส้นตรงร้านถึงหมุด (PostGIS geodesic) · 30 บาท 3 กม.แรก + กม.ละ 6 (ปัดขึ้น) · ไรเดอร์ 25 + กม.ละ 5 · เกิน 15 กม. สั่งไม่ได้ · ปรับได้ใน `.env` |
| `Order` / `OrderItem` / `OrderStatusLog` | **คัดลอกชื่อ/ราคา/ตัวเลือก ณ ตอนสั่ง** แก้หรือลบเมนูทีหลัง ออเดอร์เก่าไม่เปลี่ยน · บันทึก `rider_fee` (D3) |
| `place_order()` | ตรวจร้านเปิด, ตะกร้าไม่ว่าง, ไม่มีของหมด, มีพิกัด, ไม่เกินระยะ · คิดราคา/ค่าส่งซ้ำฝั่งเซิร์ฟเวอร์ · เลขออเดอร์ `TM261116-HDUX` (สุ่ม เดาลำดับไม่ได้) · จำที่อยู่ไว้ใช้ครั้งหน้า (เก็บ 5 อันล่าสุด) |
| `transition_order()` (ที่เดียวในระบบ) | ตารางสถานะที่อนุญาต · lock แถวกันกดพร้อมกัน · บันทึกประวัติทุกครั้ง · ข้ามขั้นไม่ได้ · กำลังส่งแล้วยกเลิกไม่ได้ |

**สถานะ:** รอชำระเงิน → รอตรวจสลิป → ชำระแล้ว → กำลังทำ → พร้อมส่ง → กำลังไปส่ง → ส่งสำเร็จ (ยกเลิกได้ก่อน "กำลังไปส่ง")

### หน้าลูกค้า
- **หน้าร้าน `/`**: ชื่อร้าน สถานะเปิด/ปิด เวลา เบอร์ · แถบหมวดติดบนเมื่อเลื่อน · การ์ดเมนูมีรูป
  - เมนูมีตัวเลือก → กด + เปิดหน้าต่างเลือกตัวเลือก/จำนวน/หมายเหตุ ยอดรวมขึ้นทันที
  - เมนูธรรมดา → กด + ลงตะกร้าเลย · มีข้อความแจ้งด้านล่าง + ตัวเลขตะกร้าเปลี่ยนทันที (ไม่โหลดหน้าใหม่)
- **ตะกร้า `/cart/`**: เพิ่ม/ลด/ลบ (HTMX), เตือนของหมด, เตือนร้านปิด
- **จัดส่งและทวนออเดอร์ `/checkout/`**: ที่อยู่เดิมกดเลือกได้ · ปุ่ม "ใช้ตำแหน่งปัจจุบัน" (GPS) · แผนที่ปักหมุด (เมื่อตั้ง `GOOGLE_MAPS_API_KEY`) · ค่าส่งคิดทันทีเมื่อได้พิกัด · ชื่อ/เบอร์เติมจากบัญชีให้
- **ออเดอร์ของฉัน `/orders/`**: แยก "กำลังดำเนินการ" กับ "ที่ผ่านมา"
- **รายละเอียด `/orders/<id>/`**: ขั้นตอนสถานะ, รายการ, ยอด, ที่อยู่, ยกเลิกเอง (เฉพาะตอนรอชำระ), โทรหาร้าน · **ถามสถานะทุก 10 วินาที เฉพาะตอนแท็บเปิด** ถ้าเปลี่ยนจะรีเฟรชเอง · ส่วนจ่ายเงินแสดงข้อความว่าจะเปิดใน M4

### Console เจ้าของร้าน
- **ข้อมูลร้าน `/console/shop/`**: ชื่อ เบอร์ ที่อยู่ **พิกัด** (วางจาก Google Maps หรือกด "ใช้ตำแหน่งเครื่องนี้" ตอนอยู่ร้าน) เวลาเปิด-ปิด + สวิตช์เปิดรับออเดอร์ (ไม่มีพิกัด = เปิดไม่ได้)
- **เมนู `/console/menu/`**: หมวด (เพิ่ม/แก้/ลบ — ลบหมวดแล้วเมนูย้ายไป "ไม่มีหมวด"), เมนู (เพิ่ม/แก้/รูป/ลบ), ปุ่ม "หมด/มีขาย" (HTMX), ตัวเลือกเสริม
  - รูป: JPG/PNG/WEBP ไม่เกิน 3 MB ตรวจด้วย Pillow ว่าเป็นรูปจริง
- **ออเดอร์ `/console/orders/`**: กรองสถานะ ค้นหาเลข/เบอร์/ชื่อ แบ่งหน้า · รายละเอียด + ประวัติสถานะ + ส่วนของไรเดอร์ + เปิดหมุดใน Google Maps + ยกเลิก (ต้องใส่เหตุผล)
- **ภาพรวม**: สวิตช์ร้าน, ยอดขายวันนี้ (นับเฉพาะที่ชำระแล้ว), ออเดอร์ค้าง, ออเดอร์ล่าสุด
- ทุกการแก้ไขบันทึก AuditLog · console เรียกผ่าน service/selector ของ catalog/orders เท่านั้น

### บั๊กที่เจอระหว่างทดสอบ และแก้แล้ว
1. **ข้อความแจ้ง (toast) ภาษาไทยไม่ขึ้น** — Django เข้ารหัสภาษาไทยใน HTTP header ทำให้ HTMX อ่านไม่ได้ → ใช้ `ensure_ascii=True` + test ตรวจว่า header เป็น ASCII
2. **ฟอร์มเพิ่มเมนูฟ้อง "ลำดับ จำเป็น"** — ช่องที่ค่าเป็น 0 ไม่ถูกแสดงในฟอร์ม → แก้ `_field.html` + ช่องลำดับไม่บังคับ + regression test
3. **กล่องค่าส่งหายหลังคิดครั้งแรก** — HTMX ค่าเริ่มต้นเป็น outerHTML → ระบุ `hx-swap="innerHTML"`

### ข้อจำกัดของการทดสอบ
- เบราว์เซอร์ในแอปไม่มีสิทธิ์ GPS → ปุ่ม "ใช้ตำแหน่งปัจจุบัน" แสดงวิธีแก้ถูกต้อง แต่ตอนทดสอบสั่งต้อง **จำลองพิกัด** ใส่แทน (ไม่ใช่ในโค้ดจริง) — **ต้องทดสอบ GPS บนมือถือจริง**
- แผนที่ Google ยังไม่ได้ทดสอบ (ยังไม่มี API key)

## 4. ให้ user ทดสอบเอง
1. ล็อกอิน `owner@tmpp.test` → `/console/shop/` ใส่ข้อมูลและพิกัดร้านจริง → `/console/menu/` ลองเพิ่มเมนูพร้อมรูป
2. ล็อกอิน `customer@tmpp.test` **บนมือถือ** (เครือข่ายเดียวกัน หรือรอขึ้น server ที่มี HTTPS เพราะ GPS ต้องใช้ HTTPS ยกเว้น localhost) → สั่งอาหาร → ดูหน้าออเดอร์
3. ล็อกอินเจ้าของ → `/console/orders/` → ยกเลิกออเดอร์ทดสอบพร้อมเหตุผล → ดูที่ฝั่งลูกค้าว่าสถานะเปลี่ยนเองภายใน 10 วินาที

**เปิดแผนที่ปักหมุด:** Google Cloud Console → เปิด Maps JavaScript API → สร้าง API key จำกัด HTTP referrer (`localhost:8000/*`, `tmth-th.com/*`) → ใส่ `GOOGLE_MAPS_API_KEY` ใน `.env` · ตอนขึ้นจริงควรสร้าง Map ID ของตัวเองแทน `DEMO_MAP_ID` ใน `static/js/checkout.js`
