# Module 06 — Console เจ้าของร้านให้ครบ (M9 ในแผน)

> วันที่: 17/11/2569 · สถานะ: เสร็จ · เมนู Console ไม่มีลิงก์ที่ยังไม่ทำแล้ว

## 1. ทำอะไรไปแล้ว

### ค่าส่งไรเดอร์ `/console/riders/pay/` (D3)
| ส่วน | ทำไม |
|---|---|
| การ์ดไรเดอร์ทุกคน: ยอดค้างจ่าย + กี่เที่ยว | เจ้าของเห็นทันทีว่าต้องจ่ายน้องเท่าไร (query เดียว) |
| หน้ารายละเอียด: งานที่ยังไม่จ่าย (เลขออเดอร์ เวลาส่ง ระยะ ค่าส่ง) | ตรวจได้ทีละงาน |
| ปุ่ม "จ่ายแล้ว บันทึก" + หมายเหตุ (โอน/เงินสด) | **ระบบไม่โอนเงิน** แค่บันทึกว่าจ่ายแล้ว · งานในรอบนั้นถูกผูกกับรายการจ่าย → นับซ้ำรอบหน้าไม่ได้ |
| กันบันทึกไม่ตรงกับที่จ่ายจริง | ส่งยอดที่เห็นบนจอไปด้วย ถ้าระหว่างนั้นมีงานส่งสำเร็จเพิ่ม ระบบให้กดใหม่ · lock งานกันกดสองแท็บ |
| ประวัติการจ่าย | วันที่ ยอด กี่เที่ยว ใครบันทึก หมายเหตุ |

**โครงสร้าง:** `RiderPayout` (delivery) + `Order.rider_payout` · `delivery/services/payout_service.py` · `delivery/selectors/payout_selector.py`
นับเฉพาะงาน "ส่งสำเร็จ" · งานที่ยังไม่จบ / ยกเลิก ไม่นับ

### ลูกค้า `/console/customers/`
- รายชื่อ + ค้นหาชื่อ/อีเมล/เบอร์ + จำนวนออเดอร์ที่ส่งสำเร็จ + ยอดรวม + สั่งล่าสุด (query เดียว ไม่วนนับทีละคน) · แบ่งหน้า
- รายละเอียด: ข้อมูลติดต่อ, ออเดอร์ล่าสุด 30 รายการ, **ปิดบัญชีลูกค้าที่สั่งปลอม/ก่อกวน** (เปิดคืนได้, ปิดแล้วหลุดจากระบบทันที, ประวัติไม่หาย)
- ใช้ได้เฉพาะบัญชีลูกค้า (ส่ง id พนักงานมาได้ 404)

### บันทึกการแก้ไข `/console/audit/`
- ทุกอย่างที่บันทึกไว้ตั้งแต่ M1: ใคร ทำอะไร กับอะไร ก่อน → หลัง IP · กรองตามประเภท (ออเดอร์/สลิป/เมนู/ร้าน/พนักงาน/ลูกค้า/จ่ายค่าส่ง) · ค้นหา · แบ่งหน้า
- ตัวกรอง `audit_change` แสดง `[ก่อน, หลัง]` เป็น "ก่อน → หลัง" และค่าเดี่ยว (เช่น เหตุผล) ตรงๆ

### ภาพรวม `/console/`
- เพิ่ม **ยอดขาย 7 วัน** (แท่งสีเรียบ ไม่ใช้ไลบรารีกราฟ นับวันที่จ่ายเงิน ไม่รวมยกเลิก) และ **เมนูขายดี 30 วัน**

### ดาวน์โหลดออเดอร์ (CSV)
- หน้าออเดอร์ > "ดาวน์โหลดออเดอร์" เลือกช่วงวันที่ (ไม่เกิน 1 ปี) · เปิดใน Excel ภาษาไทยได้ (มี BOM) · ส่งแบบ stream ไม่โหลดทั้งหมดเข้าหน่วยความจำ · บันทึก AuditLog ว่าใครดาวน์โหลด

### เมนู Console
- ทุกปุ่มมีหน้าจริงแล้ว: ภาพรวม, ออเดอร์, ตรวจสลิป, เมนูอาหาร, ข้อมูลร้าน, ไรเดอร์และพนักงาน, **ค่าส่งไรเดอร์**, **ลูกค้า**, **จอครัว**, **บันทึกการแก้ไข** (เอา "สาขา" ออกก่อน เพราะยังมีร้านเดียว)

## 2. ผลตรวจ
- `pytest`: **180 passed** (เพิ่ม 16) — จ่ายค่าส่งครบรอบ + งานใหม่เป็นรอบใหม่, **ยอดเปลี่ยนระหว่างกดต้องกดใหม่**, ไม่มีค้างจ่ายบันทึกไม่ได้, งานยังไม่จบไม่นับ, ลูกค้า: สถิติ/ค้นหา/รายละเอียด, ปิดบัญชีแล้ว session หลุด, ส่ง id พนักงานได้ 404, audit กรองประเภท + แสดงก่อน→หลัง, CSV มี BOM + เลขออเดอร์ + audit, ลูกค้าเข้าหน้าเหล่านี้ไม่ได้, ยอด 7 วัน/เมนูขายดี, **ไม่มีลิงก์ `#` ในเมนู**, จำนวน query หน้ารายชื่อคงที่
- เจอระหว่างเขียน test: test CSV ใช้วันที่แบบ UTC (หลังเที่ยงคืนเวลาไทยเป็นคนละวัน) → แก้ test ให้ใช้เวลาไทย (โค้ดจริงถูกอยู่แล้ว)
- **ทดสอบในเบราว์เซอร์**: ภาพรวม (กราฟ 7 วัน + เมนูขายดี), ค่าส่งไรเดอร์ ฿30 → บันทึกจ่าย → เหลือ ฿0 + ประวัติ, ลูกค้า, บันทึกการแก้ไข · จอมือถือ 375px ไม่ล้น · ไม่มีลิงก์ว่าง

1. ล็อกอินเจ้าของ → `/console/riders/pay/` ดูยอดที่ต้องจ่ายน้อง
