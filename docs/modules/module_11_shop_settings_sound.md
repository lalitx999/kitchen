## 1. ข้อมูลร้าน (`/console/shop/`)
- ชื่อ เบอร์ ที่อยู่ เวลาเปิด-ปิด (มีอยู่แล้ว)
- **ลิงก์ Google Maps แทนพิกัด**: `maps_link_service.parse_maps_input()` รับ
  ลิงก์เต็ม (ใช้ `!3d…!4d…` = หมุดสถานที่ก่อน `@lat,lng` = กึ่งกลางจอ), ลิงก์สั้น `maps.app.goo.gl` (ตาม redirect), หรือตัวเลขพิกัด
  - ลิงก์สั้นเรียกออกไปที่ Google ใน request — ข้อยกเว้นกฎข้อ 3: หน้าเจ้าของเท่านั้น นานๆ ครั้ง ต้องรู้ผลทันที · timeout 5 วิ
  - กัน SSRF: ตาม redirect เองทีละขั้น และยอมเฉพาะ https + โดเมน Google (`google.com`, `google.co.th`, `goo.gl`)
- **ภาพหน้าร้าน / ภาพปก**: `Branch.storefront_image`, `Branch.cover_image` (สาธารณะ ไม่ใช่ private) · ชื่อไฟล์สุ่มใหม่ทุกครั้ง กัน cache รูปเก่า
  · ลบไฟล์เก่าหลัง commit เท่านั้น · แสดงบนหน้าแรกลูกค้า (ปกด้านบน รูปหน้าร้านลอยทับขอบ)

## 3. จอครัวซ้อนกัน

- แตะตรงไหนก็ได้ครั้งแรก = ปลดล็อกเสียง · ปุ่ม `[data-sound-toggle]` เปิด/ปิด จำไว้ในเครื่อง
- ครัว: ออเดอร์ใหม่ดังทันที + เตือนซ้ำทุก 60 วิ · รับครบแล้วหยุด
- ไรเดอร์: มีงานรอรับ ดัง **วน** จนกดรับงาน (เหมือนเดิม)
- ลูกค้า: สถานะออเดอร์เปลี่ยน เล่น `bell-customer` แล้วโหลดหน้าใหม่ (ระบบเดิมมีไฟล์แต่ไม่ได้ใช้)

# รอบ 2 (18/11) — แก้ตามที่เจ้าของทดสอบจริง

## 1. แอปไรเดอร์บนหน้าจอโฮมค้างที่หน้าร้าน
- สาเหตุ: `manifest.start_url = "/"` = หน้าร้านของลูกค้า และบนมือถือเมนูผู้ใช้ถูกซ่อน (`d-none d-sm-block`) ไรเดอร์เลยไม่มีทางไปหน้าตัวเอง ต้องกดกระดิ่ง
- แก้: `start_url = /start/` → พาไปหน้าตามบทบาท (`core.views.app_start`) · พนักงานที่หลงมาหน้าร้านมีปุ่มกลับบนมือถือ
- ไอคอนเป็น PNG (iPhone ไม่รองรับ SVG เป็นไอคอนหน้าจอโฮม) · กลับจากพื้นหลังแล้วโหลดข้อมูลใหม่ (`pageshow`/`focus`)

## 2. รูปส่งงาน 1-4 รูป
- `DeliveryProofPhoto` (ตารางใหม่) · migration ย้ายรูปเดิมเป็นรูปแรก ไม่ย้ายไฟล์
- ช่องไฟล์ 4 ช่อง ช่องละ 1 รูป เพราะ iPhone ไม่เปิดกล้องตรงถ้าเลือกหลายรูปในช่องเดียว · ย่อรูปเป็น 1600px ก่อนส่ง

## 3. เสียงครัว/ไรเดอร์ไม่ดัง
- สาเหตุ: ปลดล็อกด้วยการเล่นแบบ muted (เบราว์เซอร์ยอมเสมอ จึงไม่ได้ปลดล็อกจริงบน iPhone) และฟังแค่ `pointerdown` ซึ่งมือถือไม่นับเป็นการกด
- แก้: เล่นแบบไม่ mute ทุกไฟล์ใน `click/touchend/keydown` · แถบ "เสียงยังไม่เปิด แตะตรงนี้" บนจอครัว/ไรเดอร์
- ข้อจำกัด: ล็อกจอ/สลับแอป หน้าเว็บหยุดทำงาน → ใช้แจ้งเตือน (FCM) แทน ต้องกด "เปิดการแจ้งเตือน" บนเครื่องนั้น

## 4. หลายสาขา (ตามที่เลือก: ลูกค้าเลือกจากรายการ · ครัวผูก 1 สาขา · ไรเดอร์ใช้ร่วมกัน)
- ลูกค้า: มี > 1 สาขาที่เปิด → หน้าเลือกสาขา · ตะกร้า 1 ใบ = 1 สาขา (เปลี่ยนสาขาแล้วล้างตะกร้า)
- Console: เมนู "สาขา" เพิ่ม/ซ่อน/แสดง · ตัวสลับสาขาบน sidebar → ข้อมูลร้าน/เมนู/จอครัว ทำกับสาขานั้น
- สาขาใหม่ซ่อนไว้ก่อน ใช้อัตราค่าส่ง/เวลาเดียวกับสาขาหลัก · ซ่อนสาขาสุดท้ายไม่ได้ · สาขาที่ซ่อนสั่งไม่ได้
- พนักงานครัว: `User.branch` · เห็น/กดได้เฉพาะออเดอร์สาขาตัวเอง (กรองใน selector) · แจ้งเตือนออเดอร์ใหม่ไปเฉพาะครัวสาขานั้น

- `test_smoke_all_pages.py`: เปิด 52 หน้า × 5 บทบาท ต้องไม่มี 500 · หน้าออเดอร์ทุกสถานะ

# รอบ 3 (18/11) — คูปอง, หน้าเลือกอาหาร/ตะกร้าแบบแอป, PWA

## 1. คูปอง (`orders.Coupon`, `coupon_service`, Console > คูปอง)
- ประเภท: ลดเป็นบาท · ลดเป็น % (มีเพดาน) · ส่งฟรี · ยอดอาหารขั้นต่ำ · ช่วงเวลา · จำนวนครั้งรวม/ต่อคน · เฉพาะสาขา · แสดงให้เลือก/รหัสลับ
- ส่วนลดหักจากยอดที่ลูกค้าจ่าย ค่าไรเดอร์ไม่ลด (ร้านรับเอง) · ไม่เกินค่าอาหาร (ส่งฟรี = ลดเท่าค่าส่ง)
- นับสิทธิ์จากออเดอร์ที่ไม่ถูกยกเลิก → ไม่จ่ายจนหมดเวลา = คืนสิทธิ์อัตโนมัติ
- ตอนสั่งจริงล็อกแถวคูปอง (`select_for_update`) ใน transaction เดียวกับสร้างออเดอร์ กันใช้เกินจำนวน
- ลบคูปองได้ ออเดอร์เก่ายังเก็บ `coupon_code` + `discount` · CSV มีคอลัมน์ส่วนลด/คูปอง

## 2. PWA
- manifest: id, shortcuts (สั่งอาหาร/ตะกร้า/ออเดอร์), ไอคอน maskable (Android)
- service worker ลงทะเบียนทุกหน้า: เก็บแค่หน้า "ไม่มีอินเทอร์เน็ต" (`/offline/`) **ไม่ cache หน้าอื่น** (ราคา/สถานะต้องสด)
- แถบโหลดบางๆ ด้านบน, เปลี่ยนหน้าแบบเฟด (View Transitions), ปุ่มยุบเมื่อกด, ไม่ซูมตอนแตะช่องกรอก (iPhone), ซ่อน footer เว็บเมื่อเปิดจากแอป
- แถบชวนติดตั้ง: Android กดติดตั้งได้ · iPhone บอกวิธี "แชร์ > เพิ่มไปยังหน้าจอโฮม" · ปิดแล้วไม่ถามอีก 14 วัน

## 3. หน้าเลือกอาหาร + สรุปคำสั่งซื้อ (ตามภาพตัวอย่างที่เจ้าของส่งมา ใช้สี/โลโก้ของ TMPP)
- กลุ่มตัวเลือก `MenuOptionGroup` (ต้องเลือก/สูงสุด N) จัดการใน Console > เมนู > แก้ไข · ตรวจกติกาซ้ำที่เซิร์ฟเวอร์
- หน้าเลือกอาหารเต็มจอ: รูปเต็มกว้าง + ปุ่มปิดกลม, ชิป "ไม่จำเป็นต้องระบุ, สูงสุด 1", ครบแล้วตัวอื่นเป็นสีเทา, หมายเหตุ, ปุ่ม - จำนวน +, ปุ่มล่าง "เพิ่มไปยังตะกร้า - ยอด"
- สรุปคำสั่งซื้อ: รูป+ชื่อ+"แก้ไข" (เปิดหน้าเลือกอาหารพร้อมค่าเดิม แล้วแทนที่บรรทัดเดิม), วงกลมจำนวน, "รายการอื่นที่คนมักสั่งด้วย" (ขายดี 30 วัน), แถบยอดรวม + "สั่งซื้อ" ติดขอบล่าง
- ช่องโค้ดส่วนลด + คูปองให้แตะเลือกอยู่ในหน้าชำระเงิน
