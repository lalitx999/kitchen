# Module 11 — ข้อมูลร้าน, ค่าส่งตั้งได้, จอครัว, เสียงแจ้งเตือน

> วันที่: 18/11/2569 · คำขอเจ้าของ: แก้ฝั่งแอดมิน 4 ข้อ

## 1. ข้อมูลร้าน (`/console/shop/`)
- ชื่อ เบอร์ ที่อยู่ เวลาเปิด-ปิด (มีอยู่แล้ว)
- **ลิงก์ Google Maps แทนพิกัด**: `maps_link_service.parse_maps_input()` รับ
  ลิงก์เต็ม (ใช้ `!3d…!4d…` = หมุดสถานที่ก่อน `@lat,lng` = กึ่งกลางจอ), ลิงก์สั้น `maps.app.goo.gl` (ตาม redirect), หรือตัวเลขพิกัด
  - ลิงก์สั้นเรียกออกไปที่ Google ใน request — ข้อยกเว้นกฎข้อ 3: หน้าเจ้าของเท่านั้น นานๆ ครั้ง ต้องรู้ผลทันที · timeout 5 วิ
  - กัน SSRF: ตาม redirect เองทีละขั้น และยอมเฉพาะ https + โดเมน Google (`google.com`, `google.co.th`, `goo.gl`)
- **ภาพหน้าร้าน / ภาพปก**: `Branch.storefront_image`, `Branch.cover_image` (สาธารณะ ไม่ใช่ private) · ชื่อไฟล์สุ่มใหม่ทุกครั้ง กัน cache รูปเก่า
  · ลบไฟล์เก่าหลัง commit เท่านั้น · แสดงบนหน้าแรกลูกค้า (ปกด้านบน รูปหน้าร้านลอยทับขอบ)

## 2. ค่าส่ง + ส่วนแบ่งไรเดอร์ (ย้ายจาก `.env` มาเก็บที่ `Branch`)
| | 3 กม.แรก | กม.ถัดไป |
|---|---|---|
| ลูกค้าจ่าย | 30 | 6 |
| ไรเดอร์ได้ | 25 | 5 |
| ร้านได้ (ส่วนต่าง) | 5 | 1 |
- ตั้งได้ในหน้าข้อมูลร้าน มีตารางตัวอย่าง 1–15 กม. · ห้ามตั้งไรเดอร์ได้มากกว่าลูกค้าจ่าย
- ทำไมย้ายจาก `.env`: เจ้าของแก้เองได้ไม่ต้อง SSH และแต่ละสาขาตั้งไม่เท่ากันได้ในอนาคต
- ลบ `DELIVERY_*`, `RIDER_*`, `MAX_DELIVERY_DISTANCE_KM` ออกจาก settings/.env.example แล้ว (ค่าเดิมเป็น default ของ migration)

## 3. จอครัวซ้อนกัน
- สาเหตุ: header จอครัวใช้ `.container-fluid` แต่ CSS จัดแถวเฉพาะ `.container-xl` → ปุ่มตกบรรทัดทับเนื้อหา
- แก้: ใส่ทั้งสอง class + `.tm-header-actions` ไม่ตัดบรรทัด · ปุ่มแจ้งเตือน/เสียงเหลือแค่ไอคอนบนจอเล็ก (ข้อความอยู่ใน title/aria-label)

## 4. เสียง (`static/js/sound.js`)
- ไฟล์เสียงเป็นไฟล์เดียวกับระบบเดิมอยู่แล้ว (md5 ตรงกัน) · ทำพฤติกรรมให้เหมือน `food/frontend/src/lib/sound.ts`
- แตะตรงไหนก็ได้ครั้งแรก = ปลดล็อกเสียง · ปุ่ม `[data-sound-toggle]` เปิด/ปิด จำไว้ในเครื่อง
- ครัว: ออเดอร์ใหม่ดังทันที + เตือนซ้ำทุก 60 วิ · รับครบแล้วหยุด
- ไรเดอร์: มีงานรอรับ ดัง **วน** จนกดรับงาน (เหมือนเดิม)
- ลูกค้า: สถานะออเดอร์เปลี่ยน เล่น `bell-customer` แล้วโหลดหน้าใหม่ (ระบบเดิมมีไฟล์แต่ไม่ได้ใช้)

## คำถามทบทวน
1. ทำไมใช้ `!3d!4d` ก่อน `@lat,lng` ในลิงก์ Google Maps
2. ถ้าคนวางลิงก์สั้นที่ redirect ไป `http://169.254.169.254` ระบบทำอะไร
3. ทำไมเสียงไรเดอร์ต้องวน แต่ครัวดังครั้งเดียวแล้วเตือนซ้ำทุก 60 วิ
