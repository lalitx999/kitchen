# M14 — จอครัว (19/11/2569)

ต้นแบบโครงหน้า: FoodTown (Kitchen Display / Kitchen Orders) · **สีใช้ตัวแปรธีมเดิมทั้งหมด** (ชมพู/เขียว/ส้ม/ดำ/แดงเดิม) ไม่มีสีใหม่

## 1. โครงหน้า (U1: แถบซ้ายพับได้)
- แถบซ้ายสีเข้ม (`--tm-ink`): **จอครัว** / **บอร์ด** / **วันนี้** · **เมนูหมด / มีขาย** / แจ้งเตือน / Console (เจ้าของ) · ด้านล่าง: สถานะร้าน + ชื่อสาขา + ออกจากระบบ
- จอใหญ่ (≥ 992px): ปุ่ม `[≡]` พับแถบเหลือไอคอน 72px (จำในเครื่องนั้น) · แท็บเล็ตแนวตั้ง/มือถือ: แถบซ่อน กดแล้วเลื่อนออกมาทับ (แตะพื้นหลังหรือกด Esc ปิด)
- หัวจอ: ชื่อหน้า + สาขา, **นาฬิกา** (วินาที), สลับสาขา (เจ้าของ), เปิดแจ้งเตือน, เปิดเสียง, **เต็มจอ** (ซ่อนเองบน iPhone ที่ไม่รองรับ), กระดิ่ง

## 2. มุมมองออเดอร์ (`/kitchen/?view=display|board` จำในเซสชันของเครื่องนั้น)
| มุมมอง | หน้าตา |
|---|---|
| **จอครัว** (ค่าเริ่มต้น) | ใบใหญ่เรียงตามเวลาจ่าย (จ่ายก่อนอยู่ซ้ายบน) · จอใหญ่ 3–4 ใบต่อแถว, แท็บเล็ต 2, มือถือ 1 |
| **บอร์ด** | 3 คอลัมน์ ใหม่ / กำลังทำ / รอไรเดอร์ (เหมือนเดิม) · มือถือเป็นแท็บ |

ใบออเดอร์:
- **หัวสีตามเวลารอ** นับจากลูกค้าจ่ายเงิน: เขียว `--tm-action` → ส้ม `--tm-accent` (ครบเวลาเริ่มเตือน) → แดง `--tm-danger` (ครบเวลาช้า) · อาหารพร้อมแล้ว = ดำ `--tm-ink` (ไม่เร่ง)
- ตัวจับเวลา `นาที:วินาที` นับในเบราว์เซอร์ทุกวินาที และเปลี่ยนสีเองเมื่อครบเกณฑ์ (ไม่ต้องรอบอร์ดโหลดใหม่ ไม่เพิ่มภาระเซิร์ฟเวอร์)
- ไรเดอร์ถึงร้านแล้ว (จาก M13) ขึ้นบนใบ
- **ต้องทำรวม**: แถบรวมจำนวนแต่ละเมนูจากใบที่ยังไม่เสร็จ (ใหม่ + กำลังทำ) คิดจากรายการที่โหลดมาแล้ว ไม่ query เพิ่ม

## 3. เกณฑ์สี (Console > ข้อมูลร้าน > "จอครัว: สีตามเวลารอ")
- `Branch.kitchen_warn_minutes` (ค่าเริ่มต้น 10) และ `kitchen_late_minutes` (15) แยกตามสาขา · migration `catalog 0004_branch_kitchen_wait_minutes`
- เวลาช้าต้องมากกว่าเวลาเริ่มเตือน (ฟอร์มตรวจ) · บันทึก AuditLog เหมือนช่องอื่นของร้าน · สาขาใหม่คัดลอกค่าจากสาขาหลัก
- แทนค่าคงที่ `LATE_AFTER_MINUTES = 15` เดิม

## 4. ยกเลิกพร้อมเหตุผล
แทนกล่องข้อความของเบราว์เซอร์ (`hx-prompt`) ด้วยหน้าต่างที่แตะเลือก: วัตถุดิบหมด / ร้านจะปิดแล้ว ทำไม่ทัน / ลูกค้าขอยกเลิก / ส่งไม่ได้ / นอกพื้นที่ / อื่นๆ (พิมพ์เอง) · ปุ่มยืนยันกดได้เมื่อเลือกแล้ว · ฝั่งเซิร์ฟเวอร์ยังบังคับต้องมีเหตุผลเหมือนเดิม + AuditLog
