# M15 — เซลเพจ `/about/` (19/11/2569)

ต้นแบบโครงหน้า: fastwork.com/selling · โทน **ขาว เทา ดำ** จากตัวแปรธีมเดิม (`--tm-surface`, `--tm-bg`, `--tm-line`, `--tm-muted`, `--tm-ink`) · **ชมพู `--tm-brand` เฉพาะปุ่มสั่ง** · ไม่มีสีใหม่ ไม่มี gradient · ไม่มี migration

## 1. ที่อยู่ (U2)
`/about/` เป็นหน้าแยก หน้าแรก `/` ยังเป็นเมนูที่สั่งได้ทันทีเหมือนเดิม → ลิงก์เดิมและแอปที่ติดตั้งแล้วไม่กระทบ · ใช้ลิงก์ `/about/` แชร์/ยิงโฆษณา · มีลิงก์ "เกี่ยวกับร้าน" ใน footer หน้าร้าน

## 3. เบลอแล้วค่อยชัด (`static/js/salespage.js`)
แต่ละส่วนเริ่ม `blur(10px)` + จาง + เลื่อนลงเล็กน้อย → ชัดเมื่อเลื่อนถึง (IntersectionObserver ทีละส่วน ชัดแล้วไม่กลับไปเบลอ)
- ไม่มี JS / เบราว์เซอร์เก่า = เห็นทุกอย่างชัดตามปกติ (เบลอเฉพาะเมื่อ JS ใส่ `sp-reveal-ready` ที่ `<html>`)
- มือถือตั้ง "ลดการเคลื่อนไหว" = ไม่เบลอ ไม่ขยับ
